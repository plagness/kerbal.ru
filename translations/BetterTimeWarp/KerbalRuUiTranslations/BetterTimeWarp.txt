# BetterTimeWarp -- ui-dict словарь окон выбора темпа варпа (быстрого и расширенного),
# настроек физики при варпе и интеграции в стоковое меню настроек (Difficulty Options).
# Источник -- linuxgurugamer/BetterTimeWarpContinued (сборка 2.3.14.2): BetterTimeWarp.cs
# (легаси-IMGUI окна, часть строк с rich-text тегами <color>/<b> -- это литералы, GUILayout
# всё равно получает их ТОЧНОЕ значение, тег переводится вместе с текстом внутри) и
# Settings.cs (GameParameters.CustomParameterUI -- рендерится стоковым экраном настроек
# сложности через UnityEngine.UI.Text, тоже патчится движком, см. заголовок
# KerbalRuUiTranslator.cs "KSP.UI.Screens settings pages").
#
# ⚠️ Общий словарь на всю игру -- сверено со всеми translations/*/KerbalRuUiTranslations/*.txt.
# Save/Cancel/Edit/Delete переиспользованы 1:1 из уже занятых значений (тот же смысл,
# см. Waterfall/Firespitter/MechJeb2/RP-1/ContractConfigurator). "Select"/"Simple"/"Advanced"/
# "Create"/"OK" не были заняты -- объявлены здесь впервые.
#
# ⚠️ НЕ переведено -- ограничения движка:
# 1) Список тёмпов варпа (QuikWarpWindow.warpNames/physNames) рисуется через
#    GUILayout.SelectionGrid -- патч добавлен в KerbalRuUiTranslator.cs (2026-08-03), два
#    предустановленных названия по умолчанию ("Standard Warp"/"Standard Physics Warp", см.
#    CurrentTimeWarp/CurrentPhysWarp в PluginData/BetterTimeWarp.cfg -- значения сверены с
#    реально установленным модом, не угаданы) переведены ниже. Остальные записи в списке --
#    пользовательский ввод (TextField), для кастомных названий перевод в принципе неприменим.
# 2) Динамическая конкатенация с рантайм-значениями -- не совпадёт с ключом словаря:
#    строки таблицы темпов "<b><color=lime>N:</color></b> <color=white>Xx</color>" (номер и
#    множитель), "Disable Index: " + число, "<b>Physics Timestep:</b> ...", "<b>Physics
#    Timescale:</b> ...", "<b>Lossless Upper Threshold:</b> ..." (все со значением
#    Time.fixedDeltaTime/timeScale), диалог "Deleted <имя> time warp rates". Заголовки
#    диалогов подтверждения удаления/редактирования -- это литерал "Better Time Warp"
#    (бренд мода, намеренно не объявлен -- остаётся как есть, см. правило не переводить
#    собственные названия модов).
# 3) toolbar[] в PhysicsSettingsWindow ("1", "1/2", "1/3", "1/4" в цветных тегах) -- числовые
#    дроби, не текст, переводить нечего (проходят через GUILayout.Toolbar, который движок
#    патчит, но менять там нечего).
# 4) Settings.cs: подсказки "Autosave Interval (min)" и "Autosave Short Interval (sec)"
#    склеены из нескольких строковых констант с \n внутри (компилятор C# сворачивает
#    конкатенацию литералов в один embedded-newline литерал атрибута) -- словарь построчный
#    (English<TAB>Russian), ключ с переносом строки одной строкой файла не выразить. Сами
#    заголовки полей переведены, эти две подсказки -- нет.
