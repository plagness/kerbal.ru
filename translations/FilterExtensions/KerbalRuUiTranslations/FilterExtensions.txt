# FilterExtensions -- словарь UI-строк редактора (VAB/SPH) для мода FilterExtensions
# (000_FilterExtensions + 000_FilterExtensions_Configs). ПОЧЕМУ ui-dict, а не MM-патч:
# имена категорий/подкатегорий в GameData/000_FilterExtensions_Configs/*.cfg -- это
# литерал `name = ...`, который САМ является идентификатором: на него ссылаются списки
# порядка `list = N,<name>` (в других файлах тоже) и по нему же мёрджатся подкатегории
# с одинаковым именем, объявленные в РАЗНЫХ .cfg (пример -- шесть вариантов
# "Data Transmitter*" в SubCategories_Antannae.cfg И SubCategories_Science.cfg).
# Патчить `@name` в обход этого реально сломать порядок/мёрдж в месте, которое легко
# пропустить. Вместо этого ловим уже ОТРИСОВАННЫЙ текст сайдбара (UGUI/TMPro) --
# байты name= в .cfg не трогаем вообще, вся машинерия FilterExtensions остаётся целой.
# Формат: Английский<TAB>Русский. Несовпадение = строка остаётся как есть (безопасно).
#
# ⚠️ Движок хранит ОДИН плоский словарь на всю игру (Dictionary<string,string>, см.
# tools/ui-translator/src/KerbalRuUiTranslator.cs, Dict[en]=ru без scope по мoду) --
# одинаковая английская строка из любого мода получает один и тот же перевод ВЕЗДЕ.
# Перед добавлением каждой строки этот файл сверен со всеми остальными
# translations/*/KerbalRuUiTranslations/*.txt (см. отчёт агента). Там, где строка уже
# была занята другим модом, ниже стоит комментарий с источником; если её текущий смысл
# подходит и для FilterExtensions -- строка объявлена здесь же с тем же значением
# (риска нет, значение идентично независимо от порядка загрузки файлов).
#
# Бренды/названия модов-источников категорий (латиница, НЕ переводим, поэтому их
# здесь нет вообще): B9 Aerospace, B9 Aerospace Procedural Wings, BDArmory, Bluedog
# Design Bureau, CCTV, Coatl Aerospace, Commonwealth Rockets / CRE, Dodo Labs, Far
# Future Technologies, Firespitter, Hephaistos, HullCameraVDS, KSP Interstellar,
# KW Rocketry, Knes, Luciole, Mandatory RCS Part Pack, Modular Rocket Systems, Near
# Future Technologies, Novapunch, Orbital ATK Antares, RLA Reborn, RN Industries*,
# RO Capsules/Engines/Tanks, SCANsat, SPEngine, Space Launch System, Squad, Tantares
# Space Technologies, Umbra Space Industries, Wild Blue Industries, DMagicOrbital
# Science, HGR & HGR_Redux, RemoteTech (сам бренд), StationPartsExpansionRedux,
# SurfaceExperimentPackage, TarsierSpaceTech, UniversalStorage, UniversalStorage2,
# ProceduralFairings, ProceduralParts, SM Marine, RCS, GPS -- реальные бренды/коды,
# оставлены латиницей и намеренно отсутствуют в этом словаре.
#
# Размерные/кодовые обозначения (Mk 2 [1.5 x 2.5 m], Size 3 [3.75 m], OPT Avatar
# [3 x 8.2 m] и т.п. -- все подкатегории "Filter by Cross-Section Profile" с числом в
# скобках) намеренно не переведены -- общепринятые в русских KSP-сообществах коды.
