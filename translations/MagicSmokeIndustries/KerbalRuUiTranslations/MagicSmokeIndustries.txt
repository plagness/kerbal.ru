# MagicSmokeIndustries — словарь UI-строк InfernalRoboticsNext.dll (ядро IR: окно управления
# сервоприводами/группами в полёте и редакторе, контекстное меню детали).
# Извлечено прямым разбором метаданных .NET (#US heap + строки из custom-attribute блобов
# KSPField/KSPEvent guiName) — НЕ строковым grep по strings(1), который путает служебные
# идентификаторы GameObject/префабов (ServoGroupMoveLeftButton, IKEndEffectorButton и т.п.,
# их в словарь не включаем — это имена объектов Unity-иерархии, а не отображаемый текст) с
# реальными подписями кнопок/тултипов.
#
# ⚠️ Пропущены строки с ЛИТЕРАЛЬНЫМ переносом строки внутри значения (\n как настоящий байт
# 0x0A в скомпилированной С#-строке, не два символа "\n"): "Hold to move\nto default position",
# "Hold to move\n to default position", "Add new group to the\n end of the list.",
# "Drag to reorder the servo\n or put it into a different group",
# "You can rename servos\n Names do not have to be unique",
# "Debug mode, no EC consumption.\nRequires scene change" — движок словаря грузит файл
# File.ReadAllLines() построчно и сравнивает точным совпадением (KerbalRuUiTranslator.cs,
# метод LoadFile/Translate), экранирование `\n` не разворачивается ни при загрузке словаря,
# ни при сопоставлении — писать в .txt настоящий перенос строки нельзя (разорвёт запись на
# две строки словаря), а писать текст "\n" как два символа гарантированно НЕ совпадёт со
# строкой в памяти игры (там правда 0x0A). Ключ с любым вариантом такой записи никогда не
# сработает — не добавляем заведомо мёртвые записи.
#
# ⚠️ Движок хранит ОДИН плоский словарь на всю игру (см. docs/MAINTAINING.md §7) — перед
# добавлением каждой строки этот файл сверен со всеми translations/*/KerbalRuUiTranslations/*.txt.
# Уже заняты (значение подходит по смыслу — переиспользуем чужой перевод, здесь НЕ объявляем
# повторно, чтобы не плодить дубли ключей): "Robotics" (FilterExtensions.txt → «Робототехника»,
# категория-фильтр в VAB/SPH), "Delete preset" (RealChute.txt → «Удалить пресет»),
# "Filter by Function" (FilterExtensions.txt/RealChute.txt → «Фильтр по функции»),
# "Toggle Motor" (BahaSP.txt → «Переключить мотор»).
# Пропущены с УЖЕ конфликтующим между собой смыслом в разных модах (RealChute vs
# RoutineMissionManager для "Manual"; ROLib vs RoutineMissionManager для "Tracking") — не
# усугубляем добавлением третьего значения, оставляем существующий (нерешённый) конфликт как
# есть, режимы ввода "Manual"/"Tracking" в контекстном меню серво останутся английскими.
