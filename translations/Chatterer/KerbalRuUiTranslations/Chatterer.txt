# Chatterer -- словарь UI-строк окна настроек радиопереговоров (GameData/Chatterer).
# Метод ui-dict: строки захардкожены в Chatterer.dll как аргументы legacy-IMGUI
# (GUILayout.Label/Button/Toggle, GUIContent) -- движок KerbalRuUiTranslator ловит их
# по точному совпадению текста (Harmony-патч на GUILayout/GUIContent/GUI.*).
# Строки лога ("[CHATR] ..."), отладочные Debug.Log/LogError и Application.* --
# никогда не попадают на экран игроку, исключены сознательно.
#
# Формат: Английский<TAB>Русский. Несовпадение = строка остаётся как есть (безопасно).
#
# Не переведено сознательно -- коллизия с чужим словарём другого смысла:
# "Rate: " (параметр частоты модуляции хоруса, см. Chorus modulation rate) уже занята
# translations/RP-1/KerbalRuUiTranslations/RP0.txt -> "Темп: " (темп/скорость игрового
# времени карьеры RP-1 -- другой смысл). Движок хранит один плоский словарь без scope
# по моду (см. tools/ui-translator/src/KerbalRuUiTranslator.cs), переопределять чужую
# строку здесь означало бы либо сломать перевод RP-1, либо получить непредсказуемый
# результат в зависимости от порядка загрузки файлов. Оставлено английским.
# Rate: 	(намеренно не объявлено)
#
# Quindar -- позывной тон NASA перед радиопередачей; SSTV -- Slow-Scan Television,
# радиопротокол передачи изображений. Оба -- устоявшиеся англоязычные термины
# реальной космонавтики/радиосвязи, оставлены латиницей намеренно.
# Blizzy78 -- ник автора альтернативного тулбара (мод Toolbar Controller), имя
# собственное, латиницей.
