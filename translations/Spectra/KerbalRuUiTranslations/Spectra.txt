# Spectra — русская локализация UI
# Формат: Английский<TAB>Русский.
#
# Метод: Spectra — визуальный пак (EVE-облака + Scatterer-конфиги атмосферы/океана),
# сам не содержит DLL и своего GUI. Единственный реальный пользовательский текст —
# имена пресетов качества в Spectra_Scatterer/qualityPresets.cfg (поле `name` каждого
# Quality_preset): их читает и рисует как подписи переключателя пресетов ГОТОВЫЙ GUI
# самого Scatterer (уже переведён, см. translations/Scatterer) — движок ui-dict
# перехватывает рендер текста по значению строки независимо от того, какой мод её
# предоставил, поэтому подписи пресетов ложатся в свой собственный файл (это данные
# Spectra, не код Scatterer).
#
# Проверено и НЕ включено в остальной части мода:
# - EVE_CLOUDS/textures `name = MohoAblationOuter` и т.п. — внутренние идентификаторы
#   слоёв облаков/текстур, не естественный текст (видны только в служебном списке
#   редактора конфигов EVE, не имена для игрока).
# - planetsList*.cfg `celestialBodyName` — стандартные имена тел, дропдаун Scatterer
#   резолвит их через CelestialBody.displayName (уже переведено стоковой локализацией).
# - Sunflares/*.cfg, textures.cfg, config.cfg — параметры без text/title/description.
#
# "Low"/"Medium"/"High" из того же списка пресетов уже объявлены в
# translations/PlanetShine/KerbalRuUiTranslations/PlanetShine.txt с тем же смыслом
# (уровень качества) — переиспользуются, повторно не объявляем во избежание дубля
# ключей одного смысла в плоском словаре.

Integrated	Встроенная
Very low	Очень низкое
Very High	Очень высокое
