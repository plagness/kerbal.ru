## «Оператор» — играбельность

Проверено на M1 Pro / 16 ГБ, KSP 1.12.5 (ru). GameData ~6,3 ГБ, ~7,5 тыс. MM-патчей, загрузка ~6 минут.
**Рантайм чистый** — во время игры исключений нет, весь шум только на загрузке. Дерево техов заполнено
(CTT-fill + Beamed Power + EPL).

## Открытые вопросы

### Наши
- [ ] **`install.ps1` не нужен** — Windows-путь закрыт `.ckan`-метапакетом и ZIP-архивом (v26.14).
      Формально пункт можно закрывать; оставлен как напоминание проверить, не просят ли пользователи терминальный путь.
- [ ] **`progress.md`** — рабочий дневник старого концепта, ни на что не ссылается. Либо в `docs/archive/`, либо удалить.
- [ ] **`perf/`** — профили производительности под RP-1 declutter. Живы и описаны в [PERFORMANCE.md](PERFORMANCE.md),
      но к «Оператору» отношения не имеют; при следующей ревизии — привязать к сборке `rp1` явно.
- [ ] **`data/project.json`** — секции `inventory`/`coverage`/`mods`/`uiTranslation` и `site.content.hero.lead`/`about`
      обслуживают только `/KSP-RO`; хаб их не читает. Помечено в `_concept`, разбирать при рефакторинге страницы RO.

### Чужие моды (не чиним, знаем)
- **Background Resource Processing на Apple Silicon**: `BackgroundSolarPanel.GetBehaviour` бросает
      `NullReferenceException` пачками. Пока аппарат в фокусе — не влияет; в фоне у него не учитываются панели,
      то есть батареи разряжаются без подзарядки. Баг совместимости мода, не сборки.
- **ReStock**: `Cannot replace texture 'orange-jumbo-'` (18×) — косметика.
- **`Cannot find PartModule 'KethaneWetMassIndicator'`** (16×) — мод ждёт Kethane, мы его не ставим.
- **US2**: `Cannot clone model US_M_Wedge_ScienceBay` (13×). Ни одна из этих ошибок не ломает игру.

### Не наше, но ловим в поддержке
- **CommNet Constellation**: наземные станции могут остаться без частот, и тогда связи нет никогда —
      при этом всё выглядит исправным. Диагностика и починка описаны в вики:
      [«Частоты и наземные станции»](https://kerbal.ru/Operator/wiki/chastoty.html),
      [«Диагностика связи»](https://kerbal.ru/Operator/wiki/diagnostika-svyazi.html).

## Что закрыто за последние заходы

- **33 MM-ошибки** — пробел в селекторе узла (`@AGENT[Frontier Link]`); заменено на `?`, в валидатор добавлена защита.
- **~18 ошибок парсинга контрактов** — пунктуация вплотную к `@выражению` ломала Contract Configurator;
  4 контракт-пака пере-переведены со строгими правилами, проверено токенайзером.
- **107 507 исключений Burst за сессию на Mac** — Burst-компилятор несовместим с Apple Silicon;
  установщик убирает его сам, плагины остаются (на них завязан BRP).
- **PAW-метки** (183 подписи меню правого клика) — общий ui-словарь с `folder="*"`.
- **Установка на Windows без терминала** — `.ckan`-метапакет для обеих сборок.
- **Вики** — 43 статьи, включая разбор связи, частот и диагностики по реальному инциденту в игре.
- **3D-задник на подстраницах** — относительные пути к текстурам давали 404 на `/Operator/`.
- **Оформление документации** — README как витрина (бейджи, схема связей, карта документов),
  единая навигационная строка во всех `.md` (`tools/gen_docs.py`), блок «Проект в цифрах» из git.
- **Участники считаются из git**, включая соавторов из `Co-Authored-By`: API GitHub их не отдаёт,
  поэтому список собирает `tools/gen_stats.py` и подтверждает каждый аккаунт запросом к `/users/<login>`.

## Не трогаем принципиально

- **Терминал kOS** — это язык программирования, перевод сломает скрипты.
- **Ресурсы CRP** и настоящие бренды/модели — латиницей по политике умного перевода.
- **Чужие моды** мы не храним и не раздаём: их всегда ставит официальный CKAN.
